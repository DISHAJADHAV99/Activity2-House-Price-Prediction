# Activity 2 – Simple House Price Prediction Using Linear Regression

## Project Overview
This project is completed as part of the Machine Learning CIE 2 Activity 2 – Unit II: Supervised Learning – Regression.

The objective is to build a Simple Linear Regression model to predict house prices using a numerical input feature.

## Dataset Information
- Dataset Name: California Housing Dataset
- Domain: Real Estate
- Original Records: 20,640
- Original Features: 8 input features and 1 target
- Input Feature (X): MedInc
- Target Variable (y): MedHouseVal

### Dataset Source
https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_california_housing.html

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Activities Performed
1. Dataset selection and inspection.
2. Data cleaning and preprocessing.
3. Input and target feature selection.
4. Scatter plot visualization.
5. Training and testing split (80:20).
6. Linear Regression model training.
7. Prediction generation.
8. Evaluation using MAE, MSE, RMSE and R².
9. Actual versus predicted visualization.
10. New house price prediction.

## Model Details
- Algorithm: Simple Linear Regression
- Input: Median Income (MedInc)
- Target: Median House Value (MedHouseVal)
- Split: 80% Training and 20% Testing

## Results
The model was evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

Refer to the Jupyter Notebook for actual calculated results and visualizations.

## Conclusion
A Simple Linear Regression model was developed to predict house values using median income. The model was trained and tested, and its performance was evaluated using regression metrics. The activity demonstrates the application of supervised learning for continuous numerical prediction.
